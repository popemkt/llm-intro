### UnifiedSlide

> `apps\slides\src\types.ts`

Discriminated union representing a presentation slide in one of three rendering modes: code-defined
React component, database-backed block layout, or raw HTML. Used by OverviewGrid and
PresentationView.

**Properties:**

| Name | Type | Description |
|------|------|-------------|
| kind | "code" | "db" | "html" | Discriminant determining the slide rendering strategy |
| id | number | Unique slide identifier |
| groupId | number | null | Optional reference to parent SlideGroup; null means ungrouped |
| title | string | Display title of the slide |
| notes | string | Presenter notes attached to the slide |
| transition | ApiSlideTransition | null | Animation transition applied when entering this slide; null means no transition |
| codeId | string | null | (code variant only) Identifier linking to a registered code component; null if unlinked |
| component | ComponentType<SlideProps> | (code variant only) React component that renders the slide |
| blocks | Block[] | (db variant only) Ordered array of content blocks composing the slide layout |
| theme | ThemeName | (db variant only) Visual theme applied to the slide |
| background | ApiSlideBackground | null | (db variant only) Custom background override; null uses theme default |
| html | string | (html variant only) Raw HTML string rendered directly as slide content |

**Relationships:**

- belongs to ApiSlideGroup (Slide optionally belongs to a group via groupId)
- has-a ApiSlideTransition (Slide carries an optional transition animation)
- has-many Block (db variant composes content from an ordered list of blocks)
- uses SlideProps (code variant's component receives SlideProps (isActive) at render time)

## Requirements

### Requirement: LocalDeckDraftValidation

The system SHALL validate LocalDeckDraft according to these rules:
- name must be between 1 and 90 characters
- slides array must contain between 4 and 12 items

#### Scenario: DraftDeckFromPrompt
- **GIVEN** A configured local model provider with valid API key
- **WHEN** draftDeck() is called with a prompt, optional name, and slideCount
- **THEN** Returns a LocalDeckDraft with name and slides conforming to localDeckDraftSchema

#### Scenario: DraftFailsWhenProviderUnavailable
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A local model provider with available=false
- **WHEN** draftDeck() is called
- **THEN** Throws an error with the configured reason message

### Requirement: SlideValidation

The system SHALL validate Slide according to these rules:
- title must be between 1 and 90 characters
- label must be at most 60 characters
- subtitle must be at most 180 characters
- body must be at most 320 characters
- quote must be at most 220 characters
- attribution must be at most 90 characters
- bullets items must be between 1 and 120 characters each, max 6 items
- leftTitle and rightTitle must be at most 60 characters
- leftBullets and rightBullets items must be between 1 and 120 characters each, max 5 items per column
- metrics array must contain at most 4 items
- layout must be one of: title, section, bullets, two-column, quote, metrics, closing

#### Scenario: TwoColumnSlideStructure
- **GIVEN** A slide with layout 'two-column'
- **WHEN** Content is populated
- **THEN** leftTitle, rightTitle, leftBullets, rightBullets fields carry the column content

#### Scenario: QuoteSlideStructure
- **GIVEN** A slide with layout 'quote'
- **WHEN** Content is populated
- **THEN** quote field holds the pull-quote text and attribution holds the source

### Requirement: SlideMetricValidation

The system SHALL validate SlideMetric according to these rules:
- value must be at most 24 characters
- label must be at most 80 characters

#### Scenario: ValidSlideMetricAccepted
- **GIVEN** A valid SlideMetric object with all required fields
- **WHEN** The object is validated
- **THEN** Validation passes with no errors

### Requirement: LocalModelStatusValidation

The system SHALL validate LocalModelStatus according to these rules:
- available is false when OPENAI_API_KEY is absent and no OPENAI_BASE_URL is set
- When OPENAI_BASE_URL is set without an API key, key defaults to 'local'

#### Scenario: ProviderUnavailableDueToMissingAPIKey
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** Environment has no OPENAI_API_KEY and no OPENAI_BASE_URL
- **WHEN** status() is called
- **THEN** Returns LocalModelStatus with available=false and a reason describing the missing configuration

#### Scenario: ProviderAvailableWithLocalServer
- **GIVEN** Environment has OPENAI_BASE_URL set
- **WHEN** status() is called
- **THEN** Returns LocalModelStatus with available=true, baseURL set, and apiKey defaulting to 'local'

### Requirement: UnifiedSlideValidation

The system SHALL validate UnifiedSlide according to these rules:
- kind must be one of 'code', 'db', or 'html'
- id must be a number (non-nullable)
- title and notes must be strings (non-nullable)
- code variant: component is required; codeId may be null
- db variant: blocks array, theme are required; background may be null
- html variant: html string is required
- groupId may be null indicating an ungrouped slide
- transition may be null indicating no transition animation

#### Scenario: RenderCodeSlide
- **GIVEN** A UnifiedSlide with kind='code' and a registered ComponentType
- **WHEN** PresentationView or OverviewGrid renders the slide
- **THEN** The component is mounted with isActive reflecting the slide's active state

#### Scenario: RenderDbSlideWithThemeAndBlocks
- **GIVEN** A UnifiedSlide with kind='db', a non-empty blocks array, and a ThemeName
- **WHEN** PresentationView or OverviewGrid renders the slide
- **THEN** Blocks are laid out using the specified theme and optional background override

#### Scenario: RenderHTMLSlide
- **GIVEN** A UnifiedSlide with kind='html' and a non-empty html string
- **WHEN** PresentationView or OverviewGrid renders the slide
- **THEN** Raw HTML is injected directly as slide content

#### Scenario: GroupMembership
- **GIVEN** A UnifiedSlide with a non-null groupId
- **WHEN** OverviewGrid organises slides
- **THEN** Slide is associated with the referenced ApiSlideGroup

#### Scenario: TransitionOnSlideEntry
- **GIVEN** A UnifiedSlide with a non-null transition
- **WHEN** PresentationView advances to this slide
- **THEN** The specified ApiSlideTransition animation plays on entry

### Requirement: SlidePropsValidation

The system SHALL validate SlideProps according to these rules:
- isActive must be a boolean

#### Scenario: ActivateSlideComponent
- **GIVEN** A code-variant slide component mounted in PresentationView
- **WHEN** The presentation advances to this slide
- **THEN** Component receives isActive=true, allowing active-state animations or behaviours

#### Scenario: DeactivateSlideComponent
- **GIVEN** A code-variant slide component that was previously active
- **WHEN** The presentation advances away from this slide
- **THEN** Component receives isActive=false

### Requirement: PresentationValidation

The system SHALL validate Presentation according to these rules:
- theme must be one of: dark-green, dark-blue, light, neon, warm, ocean
- name must be non-empty

#### Scenario: ListPresentations
- **GIVEN** DataProvider is initialised
- **WHEN** presentations.list() is called
- **THEN** Returns array of all Presentation records

#### Scenario: FetchSinglePresentation
- **GIVEN** A presentation with known id exists

- **THEN** Returns the matching Presentation

### Requirement: SlideGroupValidation

The system SHALL validate SlideGroup according to these rules:
- title must be non-empty
- position must be a positive integer unique within the presentation

#### Scenario: ListGroupsForAPresentation
- **GIVEN** A presentation with id pid exists
- **WHEN** groups.list(pid) is called
- **THEN** Returns all SlideGroup records for that presentation ordered by position

#### Scenario: CollapseAGroup
- **GIVEN** A SlideGroup with collapsed=false
- **WHEN** collapsed is set to true
- **THEN** Slides within the group are hidden in the navigation panel

### Requirement: BlockValidation

The system SHALL validate Block according to these rules:
- type must be one of: text, image, iframe, shape, line, table, chart
- id must be unique within the parent slide's blocks array
- animation.preset must be one of the MANUAL_BLOCK_ANIMATION_PRESETS values
- linkTarget must be _self or _blank when present

#### Scenario: RenderTextBlock
- **GIVEN** A Slide with a Block of type text
- **WHEN** The slide is rendered
- **THEN** The markdown content is displayed at the specified canvas position with the configured font
properties

#### Scenario: HideBlock
- **GIVEN** A Block with hidden=false
- **WHEN** hidden is set to true
- **THEN** Block is excluded from the rendered slide output

### Requirement: SlideFeedbackValidation

The system SHALL validate SlideFeedback according to these rules:
- status must be one of: open, resolved
- storage must be source-marker
- resolved_at must be non-null when status is resolved
- resolved_at must be null when status is open
- text must be non-empty

#### Scenario: ResolveFeedback
- **GIVEN** A SlideFeedback with status open
- **WHEN** status is set to resolved
- **THEN** resolved_at is set to current timestamp

#### Scenario: AnchorFeedbackToDOMElement
- **GIVEN** A reviewer selects a DOM element on a rendered slide
- **WHEN** Feedback is created
- **THEN** location.domPath and location.rect capture the element's position for re-anchoring on subsequent
views

### Requirement: DeckSnapshotValidation

The system SHALL validate DeckSnapshot according to these rules:
- label must be non-empty
- slide_count must equal payload.slides.length when payload is present
- group_count must equal payload.groups.length when payload is present

#### Scenario: RestorePresentationFromSnapshot
- **GIVEN** A DeckSnapshot with a full payload
- **WHEN** Restore is triggered
- **THEN** Presentation, all slides, and all groups are replaced with snapshot payload values and
ApiDeckSnapshotRestoreResult is returned

### Requirement: DeckAssetValidation

The system SHALL validate DeckAsset according to these rules:
- kind must be one of: svg, image, video, audio, other
- name must be non-empty
- mime_type must be a valid MIME type string

#### Scenario: UseAssetInImageBlock
- **GIVEN** A DeckAsset of kind image exists in a presentation
- **WHEN** An ImageBlock is created with assetId set to the asset id
- **THEN** The block renders using the asset's content rather than an external URL
