## Purpose

Slides is a presentation authoring platform supporting three slide rendering modes: code-defined
React components, block-layout canvas, and raw HTML. It embeds an AI agent runtime for deck
generation via local OpenAI-compatible models and provides collaborative review via feedback
annotations anchored to slide source files.

- UnifiedSlide discriminated union unifies three rendering modes (code React / block canvas / raw HTML) behind a single type, enabling OverviewGrid and PresentationView to handle all variants polymorphically
