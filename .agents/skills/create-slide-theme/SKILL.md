# Create Slide Theme

Themes in this repo are product data and app tokens, not only markdown guidance.

When creating a theme:

1. Identify source: user description, brand assets, screenshots, or existing slides.
2. Define palette, typography, spacing, shape, and motion philosophy.
3. Preserve themeability by mapping decisions to existing theme tokens first.
4. Only add new token surfaces when current tokens cannot express the theme.
5. Include a demo deck or preview slide when useful.

Theme notes should include:

- palette roles;
- font stacks;
- title/body scale;
- layout grid and padding;
- reusable header/footer/eyebrow patterns;
- transition and animation tone;
- what to avoid.
