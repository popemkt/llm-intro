### Requirement: GETSlideFeedback

The API SHALL support `GET /api/presentations/:pid/slide-feedback` to list all feedback entries for a presentation, optionally filtered to a single slide.

**Request:**

```json
{
  "params": {
    "pid": "number (presentation ID)"
  },
  "query": {
    "slideId": "number (optional, filter by slide)"
  }
}
```

**Response:**

```json
{
  "items": "ApiSlideFeedback[]",
  "ApiSlideFeedback": {
    "id": "string",
    "presentation_id": "number",
    "slide_id": "number",
    "slide_kind": "string",
    "slide_title": "string",
    "status": "open | resolved",
    "text": "string",
    "location": "SlideFeedbackSourceLocation",
    "storage": "source-marker",
    "created_at": "string (ISO8601)",
    "updated_at": "string (ISO8601)",
    "resolved_at": "string | null"
  }
}
```

#### Scenario: ListAllFeedbackForAPresentation
- **GIVEN** A presentation with ID 1 exists and has feedback on multiple slides

### Requirement: POSTSlideFeedback

The API SHALL support `POST /api/presentations/:pid/slide-feedback` to create a new feedback entry on a specific slide (code or html slides only). persists as a source marker in the slide's source file.

**Request:**

```json
{
  "params": {
    "pid": "number (presentation ID)"
  },
  "body": {
    "slideId": "number (required, positive integer)",
    "text": "string (required, non-empty after trim)",
    "location": "Partial<SlideFeedbackSourceLocation> (optional)"
  }
}
```

**Response:**

```json
{
  "id": "string (e.g. 'c-a1b2c3d4')",
  "presentation_id": "number",
  "slide_id": "number",
  "slide_kind": "string",
  "slide_title": "string",
  "status": "open",
  "text": "string",
  "location": "SlideFeedbackSourceLocation",
  "storage": "source-marker",
  "created_at": "string (ISO8601)",
  "updated_at": "string (ISO8601)",
  "resolved_at": "null"
}
```

### Requirement: PATCHSlideFeedback

The API SHALL support `PATCH /api/presentations/:pid/slide-feedback/:sid/:feedbackId/resolve` to mark an existing feedback entry as resolved. updates the source marker in the slide's source file with resolved status and timestamp.

**Request:**

```json
{
  "params": {
    "pid": "number (presentation ID)",
    "sid": "number (slide ID)",
    "feedbackId": "string (feedback entry ID, e.g. 'c-a1b2c3d4')"
  }
}
```

**Response:**

```json
{
  "id": "string",
  "presentation_id": "number",
  "slide_id": "number",
  "slide_kind": "string",
  "slide_title": "string",
  "status": "resolved",
  "text": "string",
  "location": "SlideFeedbackSourceLocation",
  "storage": "source-marker",
  "created_at": "string (ISO8601)",
  "updated_at": "string (ISO8601)",
  "resolved_at": "string (ISO8601)"
}
```

#### Scenario: ResolveFeedbackOnACodeSlide
- **GIVEN** Presentation 1, slide 2 (code) has open feedback with id 'c-abc12345'
- **WHEN** PATCH /api/presentations/1/slide-feedback/2/c-abc12345/resolve is called
- **THEN** 200 OK with ApiSlideFeedback object, status='resolved', resolved_at set, marker updated in source
file

#### Scenario: ResolveFeedbackOnAnHTMLSlide
- **GIVEN** Presentation 1, slide 3 (html) has open feedback with id 'c-def67890'
- **WHEN** PATCH /api/presentations/1/slide-feedback/3/c-def67890/resolve is called
- **THEN** 200 OK with ApiSlideFeedback object, status='resolved', marker updated in slide HTML
